# Windows 手工验收矩阵

在发布候选产物上执行本矩阵。记录应用构建编号、模拟器精确版本、ADB 版本、执行人和日期；提交记录前对路径、IP 与设备序列号脱敏。

## 环境组合

| Windows | MuMu 模拟器 12 | 雷电模拟器 9 |
| --- | --- | --- |
| Windows 10 22H2 x64 | 待验证 | 待验证 |
| Windows 11 x64 | 待验证 | 待验证 |
| Windows 11 ARM64 | 待验证（取决于模拟器兼容性） | 待验证（取决于模拟器兼容性） |

每个组合都应检查对应架构的 NSIS 安装包，并在没有 Android SDK、`PATH` 中没有 ADB 的干净环境中至少执行一次完整流程。ARM64 验收必须确认应用 PE 为 ARM64，同时记录模拟器和内置 ADB 自身是否能在该设备上运行；NSIS 安装器本身通过 Windows x86 仿真启动属于预期行为。

## 基础流程

- [ ] 首次安装后自动验证并选择内置 ADB，显示“应用内置”和版本 37.0.1。
- [ ] 自动发现模拟器自带 ADB，并允许从内置 ADB 切换到外部 ADB。
- [ ] 手动选择有效 `adb.exe` 后通过验证；选择无效文件时给出可恢复错误。
- [ ] 单台在线设备自动成为活动设备。
- [ ] 多台设备时要求用户选择；离线和未授权设备可见但不可选。
- [ ] 有效 IP/端口可以连接；无效 IP、端口和不可达端点提供明确反馈。
- [ ] “刷新截图”每次获取一帧，操作期间界面可响应且不能重复提交。
- [ ] 横向和纵向留白、窗口缩放后，画面中心与四角坐标映射正确。
- [ ] 单击画面只移动十字标记，不立即操作设备。
- [ ] X/Y 可由键盘编辑；越界值禁用“执行点击”。
- [ ] “执行点击”只在当前活动设备、当前截图和有效坐标下成功。
- [ ] 切换设备后截图与坐标立即清除。

## 异常与恢复

- [ ] 模拟器关闭、设备离线和设备未授权时不保留无效活动状态。
- [ ] ADB 超时后子进程被终止，状态栏给出重试方式，界面恢复可操作。
- [ ] ADB 返回非 PNG 数据时拒绝显示和点击。
- [ ] 连续替换截图时内存不会持续增长。
- [ ] 内置 ADB 缺失、损坏、版本或校验不符时构建失败或应用提示重新安装/选择外部 ADB，应用运行时不会下载替代文件。
- [ ] 内置 ADB 使用端口 5038；异常退出后可按 smart-socket `server-status` 返回的版本和程序路径回收自有实例，其他程序预先占用时拒绝接管，正常退出前再次核对身份，端口 5037 上的外部 ADB server 不受影响。

## 安装、升级与卸载

- [ ] x64 用户发布物只有带版本、平台和架构名称的 NSIS `.exe` 安装包。
- [ ] 安装目录包含 `adb.exe`、两个 ADB DLL、`NOTICE.txt`、`source.properties` 和 `PROVENANCE.json`。
- [ ] Windows“已安装的应用”中存在卸载入口，正常卸载后应用安装目录及内置 ADB 文件被移除。
- [ ] 升级或卸载不会删除 Android SDK、模拟器文件、用户手动选择的 ADB 或其他应用的数据。
- [ ] 安装、升级和卸载不会启动 HTTP 监听，也不会在应用运行时下载 ADB。

## 性能与资源

- [ ] ADB 列举、连接、截图和点击期间窗口可移动，状态反馈持续可见。
- [ ] 单次“刷新截图”只产生一次 `screencap` ADB 进程，不出现额外编码步骤。
- [ ] 连续替换截图 50 次后，应用内存回落到稳定区间，不随次数持续增长。
