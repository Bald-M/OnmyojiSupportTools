# ADR-0004：DeviceManager 独占活动识别与任务运行时

- 状态：接受
- 日期：2026-09-12

## 背景

活动自动挑战需要把当前截图、唯一页面识别、随机点击、超时、取消和成功次数绑定到同一活动设备。若 Vue 保存状态或决定动作，设备切换和并发 IPC 会留下过期输入窗口。

## 决策

`DeviceManager` 是活动配置使用、识别调度和任务会话的唯一设备域入口。Vue 只提交本机校准区域、显示评分并调用开始、暂停、确认恢复、停止和推进命令；它不能提交识别结果或绕过 Rust 的设备、截图和区域复核。

活动配置显式使用版本 1，绑定截图尺寸和方向。持久化视觉特征仅包含每个区域的 4×4 量化 RGB 均值，不包含 PNG、裁剪像素或游戏素材。只有唯一候选达到阈值并满足领先差值才视为识别状态。

任务只允许一个活动设备和一个会话。应用启动不恢复会话；ADB、设备或活动配置变化会取消待执行点击并暂停。未知/歧义页面、截止时间和有限重试耗尽都停止输入。只有领取奖励后识别到“返回挑战页”状态才增加成功次数。

## 取舍

Vue 通过受控命令周期性请求下一步，因此界面可以展示进度且 Rust 仍独占每一步决策。该专用状态机避免引入通用脚本语言，但配置不能跨尺寸/方向复用，也不提供 OCR、多设备或云同步。
