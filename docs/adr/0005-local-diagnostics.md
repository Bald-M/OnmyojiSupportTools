# ADR-0005：本地、受控字段的诊断日志

- 状态：接受
- 日期：2026-10-12

## 背景

Issue #8 需要在不上传设备数据的前提下定位 ADB、设备、截图、预览和点击失败。原有错误只在界面显示最终结果，无法追踪一步操作的过程。

## 决策

Tauri 启动时在程序可执行文件所在目录的 `log/` 下创建 JSONL 文件。前端为每次 IPC 生成关联 ID，Rust 在任务局部上下文中贯穿 `DeviceManager` 与 ADB 命令；预览后台任务显式携带 ID。日志只接受固定的步骤、结果、错误码、恢复动作和命令类别；版本、平台、架构及 ADB 来源使用独立的受控元数据字段，不写入原始参数、设备标识、配置或二进制内容。关键步骤成对记录开始、结果及耗时，失败记录中的恢复动作来自固定词表。ADB 文本摘要先按保守词表脱敏，再限制长度；PNG 和 H.264 仅记录字节类别与大小。单文件上限 1 MiB，最多保留三个文件。用户从界面主动打开目录或导出；应用不上传日志。

日志写入失败后停用本次运行的文件记录，设备链路继续工作。界面查询可用性并提示降级。日志不参与设备状态、安全校验或命令执行。

## 取舍

保守摘要会丢失部分底层报错原文，但能避免将未知设备标识和用户路径写入可分享文件。完整原始错误仍按既有错误路径反馈给当前界面，不进入诊断文件。更详细日志级别和远程上传不在本决策范围内。
